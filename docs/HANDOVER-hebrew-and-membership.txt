2. STANDING RULES
Never use a Star of David graphic. The site name and URL are enough.
Prose has no em dashes and no semicolons. Avoid stock AI phrasing.
Plain-text files must paste cleanly, with no markdown symbols.
On cards, Hebrew goes on the right in gold, with transliteration under it.
The owner makes art in ChatGPT. Do not promise generated images.
Prefer pages that fit the screen without scrolling, especially on phones.
The owner often works from a phone and cannot touch Cloudflare or GitHub settings. Do not make plans that need him at a computer unless unavoidable.

3. HOW THE SITE IS BUILT
Pages are generated by Python scripts in tools/ and written as static HTML. Never hand-edit generated HTML. Edit the builder and rebuild.
Rebuild command, run from the repo root:
python3 -I -W ignore tools/hebrew.py && python3 -I -W ignore tools/wordplay.py >/dev/null && python3 -I tools/hebrew_nav.py >/dev/null
tools/hebrew.py runs, in order, tools/alphabet.py, tools/numbers.py, tools/timemod.py and tools/hebrewapp.py, all sharing one set of globals (page(), CSS, wr(), rd(), E, json, re, hashlib, C for the course, LIVE, SW_REG, PWA_HEAD and several CSS strings).
tools/hebrew_nav.py runs last and rewrites the second-level menu row.
Course data: tools/hebrew_course.json, generated by /home/claude/course/build.py (outside the repo, may not survive). Each lesson has phrases (en, t, r, img), dialogue, quiz, tip, goal, intro. If the generator is missing, treat the JSON as the source.
tools/intro_he.json holds the Hebrew and transliteration of each lesson opening, keys "1" to "10". Only the Hebrew is spoken, never shown.
Icons come from /home/claude/course/icons_ab.py (outside the repo).
Shared files: style.css and tools/style.css must be edited together. srcbrowse.js and tools/srcbrowse.js likewise.

4. WHAT EXISTS (all live on main)
Hebrew hub: /hebrew/. Compact tiles: Travel Hebrew, Alef Bet, Numbers, Time, Wordplay, Cards. Collapsible footer. Promo strip for the app. Rotating banners for the Israel NOWlej series books.
Second-level menu row: Hebrew, Lessons, Alef Bet, Numbers, Time, Wordplay, Cards. It must stay on one line, down to 320px wide.
Travel Hebrew: /hebrew/travel/. Ten lessons in two columns by five rows. Each lesson has an illustrated opening with a spoken Hebrew introduction (autoplay plus a gold replay button), 9 to 11 phrases, a dialogue, flash cards, and a 10 question quiz.
Quiz scoring: 8 of 10 passes. Best score saved in the browser under localStorage keys hq1 to hq10, as JSON with b (best), l (last), d (date), p (pass date). The lesson list shows badges and a Passed n of 10 line. Failing never blocks progress. Retake is offered.
Diploma: /hebrew/travel/diploma/. Unlocks when hq1 to hq10 all have b of 8 or more. The student types a name (stored under hname) and a 1600 by 1130 canvas image is drawn in Hebrew and English, saved by share sheet or download.
Survival kit: an extra page inside Travel Hebrew with 30 phrases.
Food and menu cheat sheet: an appendix beside the survival kit, with Dishes, Drinks and sweets, and Ordering (including kosher labels).
Alef Bet: /hebrew/alphabet/. Its own installable app.
Numbers: /hebrew/numbers/. Tile shows 1 2 3 over the Hebrew words.
Time: /hebrew/time/. Days, today and tomorrow words, parts of the day, months, about 18 holidays, an eight question quiz. Links to the English Calendars section (/calendar/001/calendars-and-eras/, /calendar/002/days-of-memory/, /calendar/004/holiday-dates-2027-to-2036/) rather than repeating it.
Wordplay: daily Hebrew wordplay posts and cards, built by tools/wordplay.py.
Hebrew app: /hebrew/app/. Installable multi-tab app (Travel, Alef Bet, Numbers, Time, Wordplay, Site) built by tools/hebrewapp.py. Each tab is an iframe. News, Views, Media, NOWlej and Sources open inside the Site tab. Collapsible masthead, thin white border, hidden inner scrollbars.
Service workers have separate cache prefixes: ha- (app), ea- (alphabet), en- (numbers), et- (time). New pages must be added to the relevant pages list or they will not work offline.

7. PLANNED: SITE-WIDE MEMBERSHIP (designed, not built)
Goal: one NOWlej account for the whole site. Hebrew is the first module. Gives saved progress across devices, a way to monetise later, and usage insight.
Design agreed with the owner:
Sign-up with email and name. No passwords. A one-time code is emailed to sign in, which also proves the email is real.
Database: Cloudflare D1, suggested name nowlej-members. Tables for members, modules, entitlements, progress (scores, passes, diploma date) and an event log.
Server: a Cloudflare Worker, suggested name nowlej-members-api, with the D1 binding and an email API key (Resend suggested) stored as a secret.
Modules are rows in the database, such as hebrew-travel and alef-bet. Every member gets every module for now. A plan field on each account leaves room for Stripe later.
Free versus members: keep the first lesson of each module and the public site open. Members get full lessons, saved progress and the diploma.
Anonymous use stays possible. Local scores should carry over to the account at sign-up.
Usage tracking: counts and module names only, only for signed-in members, no browsing history.
Admin: a private page listing members and progress, with export.
Privacy: the site's legal page needs a line covering what is stored and how to delete an account. Age rule still undecided.
Build approach: write everything and test it locally against a local database and a fake email sender. Keep the registration screens hidden on the live site until the owner switches them on.
What only the owner can do, at a computer, about 20 minutes:
1. Cloudflare dashboard, Workers and Pages, D1, create the database.
2. Create the Worker and bind the database.
3. Create a Resend account, verify the sending domain, add the key as a Worker secret.
4. Send the database ID and the Worker address to Claude.
Cloudflare connectors may let Claude see existing Workers and KV, but creating the D1 database and secrets may still need the owner.
