About Israel NOWlej

Israel NOWlej is a growing, curated guide to Israel: its land, its history, its people and its news. The site is the living edition of the book Israel NOWlej: Know the Story of the Jewish Land in Maps, Timelines, Charts, and Graphics by Richard J. Koret. Every map, timeline, chart and glossary entry in the book has a permanent page here with its own ID, so a reader can scan the code in the print edition or type the address and arrive at the same place.

Around that foundation the site adds what a printed page cannot. A daily stream of news and views from Israeli and international publishers. Video chosen from credible channels. And for each topic a single NOWlej page that brings together a summary, images, video, related reading and the sources behind them.

The aim is a guide that is trustworthy and unhurried. Sources are named, image and text licenses are shown, and an editor approves what is featured.

How to use this site

Every item in the book has one permanent ID, for example MAP-002 or TL-004. The ID is the address.

Addresses

Type israelinmaps.com/map-002 in any browser. It redirects to the full page, israelinmaps.com/maps/002/zion-terrain. If a title is ever corrected the full address may change. The ID and the short address never change.

Hubs

A bare prefix opens the whole group: /map, /tl, /tbl, /dem, /rnk, /top, /size, /tour, /flora, /gl. The glossary is at /glossary and the book index at /index.

Cite a page

Each page shows a citation line and a Copy citation button, for example: Israel NOWlej (2027), MAP-002, p. 6, israelinmaps.com/map-002. The ID is enough for any later edition. The page number fits the 2027 print edition only.

Editions

The short address always shows the current version. Each edition also keeps a frozen copy, for example /2027/map-002, so a citation from the 2027 book can be checked against what the book showed. Corrections are listed on the page with a date.

Scanning a code

Each code in the book encodes the same short address. If a code is damaged, type the address printed beside it.
