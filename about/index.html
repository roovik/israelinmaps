How to use this site

Every item in the book has one permanent ID, for example MAP-002 or TL-004. The ID is the address.

Addresses

Type israelinmaps.com/map-002 in any browser. It redirects to the full page, israelinmaps.com/maps/002/zion-terrain. If a title is ever corrected the full address may change. The ID and the short address never change.

Hubs

A bare prefix opens the whole group: /map, /tl, /tbl, /dem, /rnk, /top, /size, /tour, /flora, /gl. The glossary is at /glossary and the book index at /index.

Cite a page

Each page shows a citation line and a Copy citation button, for example: Israel Mosaic (2027), MAP-002, p. 6, israelinmaps.com/map-002. The ID is enough for any later edition. The page number fits the 2027 print edition only.

Editions

The short address always shows the current version. Each edition also keeps a frozen copy, for example /2027/map-002, so a citation from the 2027 book can be checked against what the book showed. Corrections are listed on the page with a date.

Scanning a code

Each code in the book encodes the same short address. If a code is damaged, type the address printed beside it.
